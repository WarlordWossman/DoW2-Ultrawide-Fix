# Changelog

## 1.2
- Campaign: the chat window is no longer cut in half on the sector map and wargear screens.

## 1.1
- Campaign: the sector map and the wargear (equipment) screen now use the full screen width
  instead of a 16:9 strip with black bars. Applies to all factions.

## 1.0
- Main menu and the screens sharing its host (multiplayer lobby, match browser, post-match
  stats, …) use the full screen width; menu buttons, profile name and logo are no longer cut off.
- Army Painter: the army/unit selection panel is no longer hidden behind the left black bar.
